본편은 실제 Gmail + 회사 LLM. 격리 시연 모드는 삭제하지 않고 반복 검증 수단으로 유지한다.

4. 중요 변경 사용자 승인 → 변경 이력.

6. Gmail Thread·발송 History·WAITING_REPLY·중복 방지 확인.
7. 검증 결과와 한계. 실제 업무의 모든 상태를 순차적으로 지나야 완료되는 것은 아님을 설명.
