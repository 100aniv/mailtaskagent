1. 현재 보유 역량
- Python 숙련도: 초급
Python을 활용한 독립적인 개발 경험은 많지 않으나, AI의 도움을 받아 간단한 코드 실행 및 수정이 가능합니다. PowerShell 등 운영 스크립트와 인프라 자동화 업무에 대한 이해가 있습니다.
- AI/ML 경험: 기초 경험 보유
AI Boot Camp 과제 수행 경험이 있으며, 생성형 AI를 활용한 업무 문제 정의 및 서비스 기획 경험이 있습니다. 전통적인 ML 모델 학습이나 Fine-tuning 경험은 없습니다.
- LLM 활용 경험: GPT, Claude 등 활용 경험
GPT와 Claude를 업무 기획, 기술 분석, 문서 작성, 문제 해결 및 아이디어 구체화에 지속적으로 활용하고 있습니다. 프롬프트를 반복적으로 개선하고 결과를 검토하는 경험은 있으나, LLM API 및 LangChain/LangGraph 기반 개발 경험은 부족합니다.
- RAG/Agent 구현 경험: 초급
RAG 및 AI Agent의 기본 개념과 활용 구조는 이해하고 있으나, 직접 End-to-End로 구현한 경험은 없습니다. 현재 메일 기반 업무요청 관리 Agent를 프로젝트로 기획하고 있습니다.
- 프로젝트 경험:
Citrix VDI 운영, Windows 마이그레이션, 서버 패치 및 변경작업, 장애 대응 등 인프라 운영 프로젝트 경험이 있습니다.
또한 AI Boot Camp 최종과제로 메일을 통해 유입되는 업무 요청의 누락을 방지하고 Task로 관리하는 아이디어를 기획한 경험이 있습니다.

2. 학습 필요 영역
- Python 기본 문법 및 프로젝트 구조
- REST API 호출 및 JSON 데이터 처리
- 사내 LLM API 연동
- Prompt Engineering 및 Structured Output
- Agent의 상태관리 및 Action 설계
- LangGraph 또는 Python 기반 Agent Workflow 기초
- SQLite 등 Database CRUD 및 이력관리
- Streamlit 기반 Dashboard 구현
- Microsoft Graph API 및 M365 인증 구조
- 테스트 Dataset 구성 및 AI 성능평가
- Git 기반 버전관리

※ RAG, Vector DB, Multi-Agent는 기본 개념은 학습하되, 현재 프로젝트의 핵심 구현 범위에서는 우선순위를 낮게 설정하고자 합니다.

3. 기술 스택 선호도
- 개발 언어: Python
- LLM: ChatGPT, Claude
- Agent 구현: Python 기반 Agent Logic 또는 LangGraph
- API / 데이터 검증: REST API, JSON Schema, Pydantic
- Database: SQLite

4. 프로젝트 관심 도메인
- 1순위 도메인: OA / 업무 생산성 및 개인 업무 자동화
- 2순위 도메인: IT 인프라 / VDI 운영 자동화
- 관심 사유:
실제 업무에서 다수의 요청과 협의사항이 Outlook 메일을 통해 유입되고 있으며, 사용자가 직접 요청사항, 기한, 후속 메일, 회신 대기 여부 등을 기억하고 관리해야 하는 부담이 있습니다. 이 과정에서 업무 누락이나 기한 초과 가능성이 발생할 수 있어, LLM과 Agent를 활용한 개인 업무관리 자동화에 관심이 있습니다.
또한 현재 IT 인프라 및 VDI 운영 업무를 수행하고 있어 향후 메일 기반 요청관리 Agent를 인프라 운영 업무와 연계할 수 있다고 생각합니다.

5. 8주 목표 설정
- 기술 목표:
Python과 사내 LLM API를 활용하여 메일의 업무 요청 여부와 주요 정보를 추출하고, 선행·후행 메일과 기존 Task의 관계를 판단하여 Task 생성·수정·연결 및 상태 변경 Action을 결정하는 Agent를 구현합니다.
또한 Task DB와 Streamlit Dashboard를 연계하여 End-to-End 서비스로 완성하고, 합성·비식별 Mail Dataset을 활용한 정량 평가까지 수행하고자 합니다.

- 비즈니스 목표:
메일로 유입되는 업무 요청을 Task로 구조화하고, 요청사항·기한·회신 대기·완료 등 업무 상태를 지속적으로 관리하여 업무 누락 및 반복적인 메일 확인 부담을 줄이는 개인 업무관리 PoC를 완성하고자 합니다.
업무 요청 분류 정확도 90% 이상, 신규/기존 Task 연결 및 상태 변경 판단 정확도 85% 이상, 업무 정리시간 30% 이상 단축을 목표로 합니다.

- 성장 목표:
LLM을 단순 활용하는 수준을 넘어 LLM API 연동, Structured Output, Agent 상태관리 및 Action 설계, Database 및 Dashboard 구현, 테스트 Dataset 기반 성능평가까지 직접 수행할 수 있는 역량을 확보하고자 합니다.
최종적으로 소규모 AI Agent 서비스를 직접 설계·구현·검증하고, 시스템 구조와 기술 선택 이유를 설명할 수 있는 수준을 목표로 합니다.
