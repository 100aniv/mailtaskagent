# 발표와 면접 준비 — 여기만 보면 된다

제출은 끝났다. 남은 것은 **내가 이 프로젝트를 설명할 수 있는 상태가 되는 것**이다.
이 폴더가 그 목적으로만 만들어졌다. 다른 폴더는 안 봐도 된다.

> **AI 면접 형식 (7기 OT p.7):** 최종발표 **15분** + 질의응답 **5문항, 5분씩**.
> 응시 기간 **9/18 오후 2시 ~ 9/22 자정**, 편한 시간에 자유롭게. 모의면접은 제공되지만
> **본 면접은 재응시 불가.** AI 자동채점 후 휴먼 심사위원 Cross-Check.

## 읽는 순서

프로젝트를 하나도 모른다고 가정한 순서다. 총 4~5시간이면 된다.

| 단계 | 무엇을 | 시간 | 끝나면 할 수 있어야 하는 것 |
|---|---|---|---|
| **1** | 통합본 맨 앞 `30초 설명`·`3분 설명` | 10분 | 이 프로젝트가 무엇인지 말로 설명 |
| **2** | 통합본 `용어 사전` | 30분 | Agent·RAG·Guard·ASK_USER를 제 말로 풀이 |
| **3** | 02 이해와시연가이드 전체 | 1시간 | 메일 한 통이 어떤 단계를 거치는지 순서대로 |
| **4** | 통합본 2장(문제 정의) → 3장(시나리오) → 5장(구현) | 1시간 30분 | "왜 만들었나 / 어떻게 도나"에 예시를 들어 답변 |
| **5** | 통합본 6장(테스트) → 7장(E2E) → `숫자 사전` | 1시간 | 숫자를 말할 때 분모를 같이 말하기 |
| **6** | 03 면접_예상문답 Part 2 | 1시간 | 평가 기준 10개를 빈칸 없이, KPI Baseline 3단 답변, 전후 표 7행 |
| **7** | 06 발표_15분_대본 소리 내어 읽기 | 40분 | 15분 안에 끝나는지 확인 |
| **8** | 04 발표_시연_대본 (영상·Live 시연용) | 20분 | 시연 화면 순서 숙지 |

통합본 **4장(상세 설계)은 건너뛴다.** 필요할 때 펼치는 참고 자료다.
**1장(역량·기술 스택)은 마지막에 한 번** 훑으면 된다.

## 면접 전날 90분

1. `숫자 사전` 소리 내어 외우기 — 30분
2. `03 면접_예상문답` Part 2의 1-1부터 3-4까지 질문만 보고 답해 보기 — 40분
3. 막힌 질문만 통합본에서 근거 찾아 다시 읽기 — 20분

## 면접 직전 3분

`30초 설명` → `전후 표` 한 줄씩 → `KPI Baseline 3단 답변`.

## 가장 많이 나올 질문 하나

> "KPI가 전부 100%인데 이전에는 얼마였나? 무엇 대비 좋아진 건가?"

여기서 얼버무리면 나머지가 다 약해진다. 답은 03 면접_예상문답의 `가장 중요한 질문 — KPI Baseline`에 있다.
핵심만: **정확도의 비교 대상은 사람이 아니라 미리 써 둔 정답셋이고, 시간 KPI는 못 쟀다고 먼저 말한 뒤 측정 설계를 말한다.**

## 자료를 다시 만들려면

```bash
python scripts/build_study_book.py          # 01 통합본 (md·docx·pdf)
python scripts/build_study_docs.py          # 03·06 (docx·pdf)
python scripts/check_interview_coverage.py  # 발표자료의 모든 항목에 답변이 있는지 대조
python scripts/build_learning_guide.py      # 02 docx
python scripts/build_learning_guide_pdf.py  # 02 pdf
```
